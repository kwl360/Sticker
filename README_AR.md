# KWL360 WATS — Android

هذه ملفات مصدر المستودع الحالي `kwl360/Sticker`. ينتج GitHub Actions ملف APK تجريبيًا عند تشغيل البناء.

## الإصدار 0.8.1

- كل ZIP مستورد يُحفظ كحزمة منفصلة، وتبقى الحزم السابقة محفوظة.
- شاشة الحزم تتيح اختيار الحزمة المراد مراجعتها وإرسالها.
- زر الإرسال يطلب الاختيار بين WhatsApp العادي وWhatsApp Business.
- زر مستقل يستورد الحزمة الثابتة المختارة إلى حساب Telegram عبر واجهة الاستيراد الرسمية؛ إنشاء الحزمة ومتابعة نشرها يتمان داخل Telegram.
- استيراد Telegram في هذا الإصدار للملصقات الثابتة فقط؛ الملصقات المتحركة بصيغة WebP غير مدعومة من واجهة الاستيراد.
- ترحيل بيانات الحزمة الواحدة في الإصدار السابق إلى نظام الحزم المتعددة عند التحديث.
- يواصل التطبيق التحقق من WebP والنوع الثابت/المتحرك والمقاس والحدود قبل قبول الحزمة.
- الإصدار 0.8.1 / versionCode 2 (حزمة أندرويد جانبية للاختبار).
- اعتماد أيقونة KWL360 المرفقة وألوانها في أيقونة التطبيق والواجهة.
- هذا بناء منفصل بمعرّف تطبيق جديد ليُثبت بجانب 0.7.0؛ لا يحذف النسخة القديمة، لكن يجب إعادة استيراد ملفات ZIP للحزم إلى النسخة الجديدة.

## البناء والاختبار

شغّل سير العمل `Build Android APK` من تبويب Actions. يحتوي الـartifact المضغوط على APK؛ فك الضغط لاستخراج ملف `.apk` قبل تثبيته. يجب اختبار استيراد أكثر من ZIP، تبديل الحزم، والإرسال إلى واتساب وتليجرام على هاتف فعلي؛ نجاح البناء وحده لا يثبت اكتمال التكامل.
